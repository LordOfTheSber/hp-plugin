HP Theme для Obsidian — макеты

Плагин Obsidian, который превращает хранилище в гостиную одного из факультетов Хогвартса. Палитры и шрифты — тема, плагин добавляет переключение факультетов, Распределяющую шляпу и пасхалки. Цвета на этой странице берутся из src/houses.ts (через сгенерированный tokens.js), поэтому макеты и реализация используют одни и те же значения.

1. Принципы

Что меняется

  • Четыре факультета. Светлая тема Obsidian → «Пергамент», тёмная → «Гостиная». Переключение светлой/тёмной — штатное, плюс заклинания.
  • Только переменные Obsidian (--background-primary, --text-normal, --interactive-accent…): работает в редакторе, просмотре, канвасе, графе, настройках и с другими плагинами.
  • Орнаменты (отключаемые): золотая нить под заголовком заметки, разделитель ✦, акцент активной вкладки и файла.
  • Статус-бар: факультет и очки. Лента: меню факультетов, Шляпа.

Читаемость — главное ограничение

  • Текст заметок — Literata (создан для чтения с экрана, есть кириллица). Заголовки — Forum, классическая антиква без завитушек.
  • Интерфейс (меню, настройки, боковые панели) остаётся на системном шрифте: на мелких размерах он читается лучше антиквы.
  • Свой шрифт из «Настройки → Оформление» имеет приоритет над шрифтом темы.
  • Контраст текста ≥ 7:1 на всех фонах (заметка, панели, выделение, маркер), ссылок и второстепенного ≥ 4.5:1 — проверяется тестом.
  • Золото, серебро, бронза — только линии и орнаменты, не текст. Анимации отключаются при «уменьшении движения».
